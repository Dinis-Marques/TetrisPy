# TetrisPy
This project is a Tetris game developed in Python using PyGame, created as my final project for the 10th grade Programming course.

Due to the limited time spent learning PyGame, the project was initially based on a tutorial.I modified and expanded the game to meet all the requirements defined by the teacher and to fully complete the assignment.


References used:
Tetris tutorial using PyGame: https://github.com/educ8s/Python-Tetris-Game-Pygame
Main menu and button system: https://github.com/russs123/pygame_tutorials/tree/main/Button
